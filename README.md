 Helios AI — Autonomous Space Biolab Intelligence Platform

Helios AI is an enterprise-style AI platform designed for autonomous biological experiment monitoring in space environments.

The platform provides:

- Scientific telemetry monitoring
- AI-powered scientific assistant
- Anomaly detection
- Mission risk scoring
- Machine learning prediction engine
- Scientific RAG document analysis
- Knowledge graph generation
- Automated mission report generation

## 🧠 Features

- Premium futuristic dashboard UI
- Scientific dataset upload system
- AI-based mission analysis
- Isolation Forest anomaly detection
- Prediction engine for experiment outcomes
- Risk assessment engine
- PDF mission reporting
- FAISS-powered document retrieval
